# Security policy

## Reporting a vulnerability

Do not publish exploit details, credentials, personal data or an unpatched vulnerability in a public issue or pull request.

Please send a private report to the maintainer contact listed in the repository publisher metadata. Include the affected path/version, impact, minimal reproduction steps and any suggested mitigation. Remove personal or patient-identifying data from the report.

## Scope and limitations

This repository contains prompt/skill instructions, schemas and static validation code. A passing static test does not prove the security of a deployed host, external AI provider, renderer, media artifact or institutional workflow. Prompt-injection pattern checks are heuristic and are not a security guarantee.

Do not submit real patient records, secrets, API keys or confidential institutional material in issues, pull requests or test fixtures.
