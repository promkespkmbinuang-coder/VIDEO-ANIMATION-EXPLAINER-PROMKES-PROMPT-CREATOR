# Visual, motion and audio reference production

## Visual reference Guide

The Master Visual Style Guide records art medium, line/shape language, color palette, texture/material, lighting, composition, safe areas, rendering approach and prohibited drift. The Character Guide records identity, proportions, hairstyle, wardrobe, accessories, expression/pose ranges and allowed variations. The World & Environment Guide records location layout, props, scale and recurring spatial rules.

S08 converts these accepted records into still/reference prompts: style references, character sheets, pose/expression references, environment plates, prop references and scene keyframes. A reference prompt requests one image/state, not a moving clip.

## Motion reference data

S07 describes motion separately using element IDs, start/end states, key poses, frame/time range, position/scale/rotation/opacity, path, easing intent, overlap and transition IDs. These values are reference data for a downstream renderer or animator.

## Voice and audio references

S09 supplies VO performance, speaker identity, pronunciation, cue IDs, start/end times, music mood/rights direction, ambience, sound effects and mix references. Exact script remains traceable to S04 and source facts to S02.

## Exact text and overlay data

Institutional names, logos, numbers, dates, locations, contact details, health claims and CTA must remain separate, editable overlay/subtitle records. Do not depend on generated reference image text for factual accuracy.

## Handoff

The production handoff maps approved reference asset IDs, scene timing, layers, transitions, overlays, subtitles and audio cues. It remains renderer-neutral and is not a video file or Remotion project. Downstream rendering requires actual assets, implementation, environment and artifact QA.
