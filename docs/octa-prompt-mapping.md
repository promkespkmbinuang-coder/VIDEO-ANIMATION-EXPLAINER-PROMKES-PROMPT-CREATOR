# Octa-Prompt mapping

| Pillar | Application in this plugin |
|---|---|
| P1 Role & Persona | M00 and specialists with bounded domain ownership and human authority |
| P2 Objective & Task | Prompt-to-reference intent, requirements, task matrix and acceptance |
| P3 Context & Variables | Poster/caption source status, claim registry, variables, Guide versions and placeholders |
| P4 Reasoning & Workflow | Dependency flow, reference selection, storyboard-to-asset pipeline and renderer handoff |
| P5 Constraints & Guardrails | Health truth, privacy, consent, intellectual property, prompt injection, no text-to-video/no render claims |
| P6 Edge Cases & Recovery | Missing/unreadable source, conflicting facts, unsupported image model, missing reference asset and stale Guide locks |
| P7 Stop & Completion | Reference-handoff readiness distinct from reference asset approval, rendering, artifact QA and publication |
| P8 Output Schema | Prompt-to-reference records, reference manifest, renderer-neutral scene handoff and QA report |

The eight pillars are designed proportionally. A static reference package is not proof of rendered media correctness.
