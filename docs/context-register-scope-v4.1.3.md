# Context register scope — V4.1.3

The V4.1.3 register expands the bounded context index from 19 to 26 records. Newly explicit records cover:
- static infographic 1080×1350 px / 4:5 / top-bottom logo-safe space, without applying those settings to video;
- optional social discovery and engagement aspirations, without promising FYP, trending, virality or reach;
- optional metaphor/hyperbole, bounded by S02 health fact locks;
- campaign-scoped environmental-care CTA;
- modern/youth-aware aesthetic as an editable style direction, not a demographic assumption;
- unresolved product/plugin/repository identity naming; and
- a legacy V3 test ledger boundary, so old V3 PASS records cannot substantiate V4.1.3.

The register remains `PARTIAL_WITH_DISCLOSED_BOUNDARY`: it uses current conversation, available prior-conversation summaries and selected private/GitHub read-backs, not the complete raw chat corpus. It is not clinical evidence, campaign-fact verification, permission, identity proof or test evidence.
